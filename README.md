В проекте реализован набор тестов для проверки различных аспектов функциональности класса `BooksCollector`, используя библиотеку `pytest`.
Подробное описание тестов
Тест на добавление книг:
test_add_new_book_add_two_books: Проверяет возможность добавления двух книг и соответствие количества этих книг.
Тест на добавление книги с длинным названием:
test_add_new_book_long_name: Проверяет, что книга с слишком длинным названием не добавляется.
Тест на установку жанра:
test_set_book_genre: Параметризованный тест для установки жанра книги. Проверяет установку жанра для нескольких книг.
Тест на установку неверного жанра:
test_set_book_wrong_genre: Проверяет, что жанр книги не меняется, если пытаемся установить жанр для несуществующей книги.
Тест на получение жанра книги:
test_get_book_genre: Проверяет правильность получения жанра для конкретной книги.
Параметризованный тест на получение жанров всех книг:
test_get_books_genre: Проверяет получение словаря всех книг с соответствующими жанрами.
Тест на установку жанра для несуществующей книги:
test_set_book_genre_invalid_book: Проверяет, что нельзя установить жанр для книги, которая не существует.
Тест на получение книг по жанру:
test_get_books_with_specific_genre: Проверяет возможность получения книг с заданным жанром.
Тест на получение книг для детей:
test_get_books_for_children: Проверяет, что метод возвращает только книги, подходящие для детей.
Тест на добавление книги в избранное:
test_add_book_in_favorites: Проверяет возможность добавления книги в избранное.
Тест на повторное добавление книги в избранное:
test_add_book_in_favorites_again: Проверяет, что повторное добавление не увеличивает количество избранных книг.
Тест на удаление книги из избранного:
test_delete_book_from_favorites: Проверяет возможность удаления книги из избранного.
Параметризованный тест на получение списка избранных книг:
test_get_list_of_favorites_books: Проверяет получение списка избранных книг в различных сценариях.
