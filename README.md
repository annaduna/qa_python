# BooksCollector Project

Этот проект содержит класс `BooksCollector`, который управляет коллекцией книг. В этом файле описываются тесты, реализованные для проверки функциональности данного класса.

## Описание тестов

В проекте реализованы следующие тесты для проверки метода `BooksCollector`:

### 1. Тест на добавление новых книг
- **`test_add_new_book_add_two_books`**: Проверяет добавление двух книг и корректную регистрацию их количества.

### 2. Тест на долгие названия книг
- **`test_add_new_book_long_name`**: Проверяет, что книга с слишком длинным названием не добавляется в коллекцию.

### 3. Тест на установку жанра книги
- **`test_set_book_genre`**: Использует параметризованные тесты для проверки установки жанра для различных книг.

### 4. Тест на установку неправильного жанра
- **`test_set_book_wrong_genre`**: Проверяет, что если жанр устанавливается для несуществующей книги, то жанр не изменяется.

### 5. Тест на получение жанра книги
- **`test_get_book_genre`**: Проверяет, возвращает ли метод правильный жанр для заданной книги.

### 6. Тест на получение жанров книг
- **`test_get_books_genre`**: Использует параметризованный тест для проверки получения жанров нескольких книг.

### 7. Тест на установку жанра для несуществующей книги
- **`test_set_book_genre_invalid_book`**: Проверяет, что получение жанра для несуществующей книги возвращает None.

### 8. Тест на получение книг с определённым жанром
- **`test_get_books_with_specific_genre`**: Проверяет, возвращает ли метод список книг с заданным жанром.

### 9. Тест на получение книг для детей
- **`test_get_books_for_children`**: Проверяет, что возвращается правильный список книг для детей.

### 10. Тест на добавление книг в избранное
- **`test_add_book_in_favorites`**: Проверяет, что книга может быть добавлена в список избранных.

### 11. Тест на повторное добавление книги в избранное
- **`test_add_book_in_favorites_again`**: Проверяет, что повторное добавление уже избранной книги не меняет количество книг в избранном.

### 12. Тест на удаление книги из избранного
- **`test_delete_book_from_favorites`**: Проверяет, что книга может быть удалена из списка избранных.

### 13. Тест на получение списка избранных книг
- **`test_get_list_of_favorites_books`**: Использует параметризованные тесты для проверки получения списка избранных книг.
